# Bug: Drizzle Schema Divergence on Trigram GIN Indexes

- **Bug ID**: 15
- **Category**: Maintainability
- **Severity**: Medium
- **Target Files**:
  - `server/src/db/migrations/0000_mute_martin_li.sql` (lines 226–230)
  - `server/src/db/schema/tournaments.ts`
  - `server/src/db/schema/teams.ts`
  - `server/src/db/schema/users.ts`
  - `server/src/db/schema/marketplace.ts`
- **Status**: Identified

---

## 1. Description

The baseline SQL migration `server/src/db/migrations/0000_mute_martin_li.sql` explicitly establishes five PostgreSQL GIN trigram indexes to support performant fuzzy text search across titles, names, usernames, and in-game IDs:
```sql
CREATE EXTENSION IF NOT EXISTS pg_trgm;--> statement-breakpoint
...
CREATE INDEX IF NOT EXISTS "tournaments_title_trgm_idx" ON "tournaments" USING gin ("title" gin_trgm_ops);--> statement-breakpoint
CREATE INDEX IF NOT EXISTS "teams_name_trgm_idx" ON "teams" USING gin ("name" gin_trgm_ops);--> statement-breakpoint
CREATE INDEX IF NOT EXISTS "profiles_username_trgm_idx" ON "profiles" USING gin ("username" gin_trgm_ops);--> statement-breakpoint
CREATE INDEX IF NOT EXISTS "profiles_in_game_id_trgm_idx" ON "profiles" USING gin ("in_game_id" gin_trgm_ops);--> statement-breakpoint
CREATE INDEX IF NOT EXISTS "marketplace_title_trgm_idx" ON "marketplace_listings" USING gin ("title" gin_trgm_ops);
```

However, these GIN indexes are completely absent from the declarative Drizzle ORM TypeScript schema definitions:
- `server/src/db/schema/tournaments.ts` does not define `tournaments_title_trgm_idx`.
- `server/src/db/schema/teams.ts` does not define `teams_name_trgm_idx`.
- `server/src/db/schema/users.ts` does not define `profiles_username_trgm_idx` or `profiles_in_game_id_trgm_idx`.
- `server/src/db/schema/marketplace.ts` does not define `marketplace_title_trgm_idx`.

Because Drizzle ORM uses TypeScript schema declarations as the authoritative source of truth for schema state, running `npx drizzle-kit generate` or `npx drizzle-kit check` interprets these database indexes as untracked artifacts and generates migration statements to drop them (`DROP INDEX "tournaments_title_trgm_idx";`, etc.). This causes severe schema divergence between code and database migrations, violating the project's declarative migration invariant.

---

## 2. Specification & Design Reference

- `docs/internal/design/lld/database-schema.md`: "All database indexes, constraints, and extensions must be declaratively modeled in Drizzle ORM schema definitions."
- `docs/internal/architecture-overview.md` Section 3: "Declarative Single Source of Truth: Drizzle schemas under `server/src/db/schema/` drive database migrations and type contracts."

---

## 3. Reproduction Steps / Proof of Concept

1. Inspect `server/src/db/schema/teams.ts`, `tournaments.ts`, `users.ts`, and `marketplace.ts`.
2. Notice none of the tables declare `index('...').using('gin', sql`... gin_trgm_ops`)` in their table callback definitions.
3. Run `npx drizzle-kit generate` against the existing database schema.
4. Drizzle Kit flags the missing declarations and generates SQL migrations to drop the GIN trigram indexes created by `0000_mute_martin_li.sql`.

---

## 4. Impact

1. **Catastrophic Search Performance Degradation**: If migrations generated by Drizzle Kit are applied to staging or production, the GIN trigram indexes are dropped. Subsequent `ILIKE` and trigram similarity queries on `tournaments`, `teams`, `profiles`, and `marketplace_listings` will degrade from indexed log-time lookups to sequential full-table scans.
2. **Schema Drift and Pipeline Failures**: CI/CD schema verification checks (`drizzle-kit check` or migration linters) fail due to unmanaged schema divergence between the SQL migrations and the TypeScript schemas.

---

## 5. Recommended Remediation

Update the Drizzle table declarations in `server/src/db/schema/` to explicitly declare the GIN trigram indexes using Drizzle's `.using('gin', sql`${column} gin_trgm_ops`)` syntax, ensuring 100% parity between TypeScript schemas and generated migrations:

```ts
import { sql } from 'drizzle-orm';
import { index, pgTable } from 'drizzle-orm/pg-core';

// In server/src/db/schema/tournaments.ts
(table) => ({
  titleTrgmIdx: index('tournaments_title_trgm_idx').using('gin', sql`${table.title} gin_trgm_ops`),
})

// In server/src/db/schema/teams.ts
(table) => ({
  nameTrgmIdx: index('teams_name_trgm_idx').using('gin', sql`${table.name} gin_trgm_ops`),
})

// In server/src/db/schema/users.ts
(table) => ({
  usernameTrgmIdx: index('profiles_username_trgm_idx').using('gin', sql`${table.username} gin_trgm_ops`),
  inGameIdTrgmIdx: index('profiles_in_game_id_trgm_idx').using('gin', sql`${table.inGameId} gin_trgm_ops`),
})

// In server/src/db/schema/marketplace.ts
(table) => ({
  titleTrgmIdx: index('marketplace_title_trgm_idx').using('gin', sql`${table.title} gin_trgm_ops`),
})
```
